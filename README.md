# witcher3-assets

Тайлы подложки для интерактивной карты [Ведьмак 3: Дикая Охота](https://broskiplay.ru/witcher3-map/) (BroskiPlay). Раздаются через GitHub Pages.

- `tiles/<карта>/<z>/<x>/<y>.webp` и `tiles/<карта>/manifest.json` — список существующих тайлов
- Карты: `velen-novigrad`, `skellige`, `toussaint`, `white-orchard`, `kaer-morhen`, `isle-of-mists`, `vizima-castle`, `time-and-space`, `olgierd-world`, `land-of-fables`

Тайлы взяты с [lastboss.net](https://lastboss.net/witcher-3/karta) как есть (без перекодирования).
